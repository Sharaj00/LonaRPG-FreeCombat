# LonaRPG FreeCombat — Beta 0.8.11

Свободное перемещение и бой для **LonaRPG B.0.10.7.5.18**, Windows x86 / RGSS301 (Ruby 1.9.2).

Персонажи движутся свободно без тайловой системы, ближние атаки используют форму штатного навыка, а снаряды летят непрерывно. На глобальной карте остаётся штатное тайловое передвижение.

Основные системы реализованы, проведены автоматические и ограниченные игровые проверки. Полное прохождение до концовки, все классы и сюжетные ветки ещё не проверены; отсутствие ошибок во всей игре не гарантируется.

## Скачать и установить

Готовые архивы находятся в [Releases](https://github.com/Sharaj00/LonaRPG-FreeCombat/releases).

| Архив | Назначение |
|---|---|
| FreeCombatPrototype-0.8.11.zip | Основной аддон, обязателен |
| FreeCombatDiagnostics-0.2.2.zip | Необязательный журнал ошибок, маркеры и отдельные тестовые режимы |
| LonaPerformance-0.1.13.zip | Необязательные оптимизации геометрии и обработки событий |
| FreeCombatCompatibility-0.1.1.zip | Дополнительный мост для перечисленного ниже набора модов |

1. Закройте игру. Сделайте резервную копию игры и всей папки UserData. Для тестирования используйте отдельную копию игры.
2. Распакуйте нужные ZIP. В каждом находится одна папка аддона (например, `FreeCombatPrototype`). Вручную поместите её в `ModScripts/_Mods/` вашей копии игры. Итоговый путь: `ModScripts/_Mods/FreeCombatPrototype/_ModInfo.json`. Папок `ModScripts` и `_Mods` внутри ZIP нет.
3. Включите аддоны в штатном менеджере модов. Порядок: сторонние моды → FreeCombatPrototype → FreeCombatCompatibility (если нужен) → FreeCombatDiagnostics → LonaPerformance.
4. Полностью перезапустите игру. Свободный режим включается при обычной новой игре или загрузке.

Сохранения с FreeCombat требуют включённого FreeCombat: загрузка без него, удаление аддона и откат версии не поддерживаются. Для набора с RolePlay-S нужна **новая игра**; перенос старого персонажа в RolePlay-S не предусмотрен. Файлы `.free-combat.bak` — предыдущие версии перезаписанных сохранений; храните и обычную отдельную резервную копию.

Другие версии игры и произвольные сочетания модов не заявлены как совместимые. Не меняйте Game.ini Title: штатный менеджер читает оттуда версию игры.

## Диагностика и сообщения об ошибках

В основном аддоне нет отладочной панели или тестовых уровней. С включённым Diagnostics:

- F9 показывает/скрывает панель; при запуске она скрыта.
- F11 отмечает проблему без остановки игры.
- F6 из главного меню открывает изолированную арену, F7 — временный тест на карте; F8 возвращает из теста в главное меню. В F6 сброс — F5. Сохранение в тестах заблокировано.

После проблемы нажмите F11 и создайте [Issue](https://github.com/Sharaj00/LonaRPG-FreeCombat/issues): версия игры и аддонов, порядок модов, шаги, ожидаемое и фактическое поведение. Приложите журналы `UserData/FreeCombatDiagnostics/diagnostics.jsonl`, `.jsonl.1`, `.jsonl.2`, если они есть. Сначала просмотрите их: журналы содержат локальные пути и сведения о игровой ситуации.

## Производительность и ограничения

LonaPerformance уменьшает стоимость отдельных расчётов геометрии и диспетчеризации. Библиотека `geometry-x86.dll` — собственный арифметический код, не замена RGSS. Каждую оптимизацию можно отключить в settings.rb. Экспериментальный GC по умолчанию выключен (`GC_BATCH_FRAMES = 0`); оставьте так для обычной Beta.

Перед финальным стабильным релизом остаются полное прохождение, длительные бои, редкие сюжетные состояния, непроверенные сочетания навыков и ручная оценка производительности. Публикация Beta позволяет собрать эти результаты от игроков.

## Исходники и сборка

Собственные исходники четырёх аддонов находятся в `src/`; арифметическое ядро и модули оптимизации — в `src/RGSSPerformance/`. `tools/build_geometry.ps1` собирает DLL с MSVC x86, затем `python tools/build_beta_release.py` формирует архивы и SHA256SUMS. Переданный `-Compiler` должен указывать на x86 cl.exe. Закоммиченные архивы в releases/ — проверенные файлы этой Beta; публикация сверяет их контрольные суммы.
