# LonaRPG FreeCombat 0.8.12 — Beta

Для **LonaRPG B.0.10.7.5.18 / Windows x86 RGSS301**. Патчи совместимости теперь встроены в основной аддон, а порядок поддерживаемого набора настраивается автоматически.

- Отдельный FreeCombatCompatibility больше не требуется. Адаптеры включаются для успешно загруженных поддерживаемых версий модов; причина пропуска записывается в Diagnostics.
- FreeCombat учитывает зависимости и правила загрузки, сохраняет относительный порядок посторонних/отключённых модов и не включает отключённые моды.
- Если порядок пришлось изменить, предыдущий INI сохраняется в `UserData/GameMods.ini.free-combat-order.bak`, а запуск завершается с сообщением. Перезапустите игру один раз. При правильном порядке дополнительный перезапуск не нужен. Конфликт правил останавливает запуск без записи нового порядка.
- Diagnostics записывает активные адаптеры и фактический порядок загруженных модов. Его панель по-прежнему скрыта, F11 ставит маркер проблемы.

**Архивы:** FreeCombatPrototype 0.8.12, FreeCombatDiagnostics 0.2.3 и LonaPerformance 0.1.14. В каждом только папка аддона: вручную поместите её в `ModScripts/_Mods/`. Игры, сторонних модов и отдельного Compatibility в Release нет.

**Обновление:** закройте игру, сохраните резервную копию UserData и аддонов, замените папки нужных аддонов. Старый FreeCombatCompatibility можно убрать из `_Mods`; его код больше не нужен. Сохраните свои настройки LonaPerformance/settings.rb; экспериментальный GC по умолчанию выключен. Удаление FreeCombat или откат версии для его сохранений не поддерживаются. Для добавления RolePlay-S к прежнему персонажу по-прежнему нужна новая игра.

Проверенный набор: RolePlayS 0.7.9.3; шесть NPC/портретных модов 1.0; CoockingExpanded 0.5.0; Temper Trine 1.5.2; FactionClashes 0.3.22; RestJournal 3.5; предоставленная legacy-версия PassiveStaminaRegen. [Полный список со ссылками](https://github.com/Sharaj00/LonaRPG-FreeCombat#readme).

**Проверка изменений:** 187 проверок встроенной совместимости; 212 проверок сортировки; 68 игровых проверок автоматического порядка, включая сохранение/загрузку; общий RGSS-прогон 148 и назначения клавиш 17. Совместная native-загрузка окончательных версий прошла 26 проверок без ошибок. Исходники арифметического ядра и DLL не изменены; LonaPerformance получил поддержку новой версии FreeCombat.

Это Beta для дальнейшего игрового тестирования: полное прохождение, все классы/сюжетные ветки и длительная стабильность ещё не подтверждены. Неизвестные моды не становятся совместимыми только благодаря сортировке. После ошибки нажмите F11 и приложите описание и проверенные на личные данные журналы к [Issue](https://github.com/Sharaj00/LonaRPG-FreeCombat/issues).

SHA256SUMS.txt содержит контрольные суммы трёх архивов.
