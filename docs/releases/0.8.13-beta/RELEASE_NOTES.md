# LonaRPG FreeCombat 0.8.13 — Beta

Для **LonaRPG B.0.10.7.5.18 / Windows x86 RGSS301**.

- Исправлена диагональная навесная стрела скелетов-лучников, включая элитный вариант и лучников вне области непрерывного управления. Штатная дуга полёта сохранена, направление ограничено одной из четырёх осей.
- Добавлено опциональное прохождение игрока и нанятых напарников друг сквозь друга: установите `COMPANION_COLLISION = false` в `ModScripts/_Mods/FreeCombatPrototype/settings.rb` и перезапустите игру. По умолчанию коллизия включена (`true`). Действует на картах свободного управления; стены, посторонние NPC и участие спутников в бою сохраняются.
- Diagnostics записывает состояние настройки коллизии. Встроенная совместимость и автоматический порядок загрузки сохраняются; отдельный Compatibility не нужен.

**Архивы:** FreeCombatPrototype 0.8.13, FreeCombatDiagnostics 0.2.4 и LonaPerformance 0.1.15. Последний обновляет поддержку новой версии FreeCombat; арифметическое ядро, DLL и выключенный по умолчанию экспериментальный GC не изменены.

**Установка/обновление:** закройте игру, сделайте резервную копию UserData и аддонов, распакуйте нужные ZIP и вручную поместите папку каждого аддона в `ModScripts/_Mods/`. Внутри ZIP родительского пути нет. Сохраните свои настройки FreeCombatPrototype/settings.rb и LonaPerformance/settings.rb. Включите аддоны и полностью перезапустите игру; при исправлении порядка потребуется ещё один запуск. Старый Compatibility не устанавливайте.

Проверенный набор версий сторонних модов не изменился: RolePlayS 0.7.9.3, шесть NPC/портретных модов 1.0, CoockingExpanded 0.5.0, Temper Trine 1.5.2, FactionClashes 0.3.22, RestJournal 3.5 и предоставленная legacy-версия PassiveStaminaRegen. [Описание и ссылки](https://github.com/Sharaj00/LonaRPG-FreeCombat#readme).

Для обновления существующей игры с тем же набором модов новая игра не требуется. Для добавления RolePlay-S к старому персонажу начинайте новую игру. Удаление FreeCombat и откат его сохранений не поддерживаются.

**Проверки:** реальный запуск навыка скелета — 3; расширенные проверки штатных навесных стрел элитного скелета и игрока — 100; коллизия нанятого напарника — 13; общая RGSS-лаборатория — 148; назначения движения — 17. Все без ошибок. Это Beta: полное прохождение, все сюжетные состояния и длительная стабильность ещё не подтверждены.
