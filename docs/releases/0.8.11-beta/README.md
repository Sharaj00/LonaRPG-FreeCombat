# LonaRPG FreeCombat — Beta 0.8.11

Свободное перемещение и бой для **LonaRPG B.0.10.7.5.18**, Windows x86 / RGSS301 (Ruby 1.9.2).

Персонажи движутся между клетками, ближние атаки используют форму штатного навыка, а снаряды летят непрерывно. Сохранены игровые навыки, затраты ресурсов, экипировка, состояния, спутники, взаимодействия и сюжетные события. На глобальной карте остаётся штатное движение по клеткам. Направленные атаки не бьют за спину; стрельба игрока и NPC ограничена четырьмя направлениями.

Это первая публичная **Beta для игрового тестирования**. Основные системы реализованы, проведены автоматические и ограниченные игровые проверки. Полное прохождение до концовки, все классы и сюжетные ветки ещё не проверены; отсутствие ошибок во всей игре не гарантируется.

## Скачать и установить

Готовые архивы находятся в [Releases](https://github.com/Sharaj00/LonaRPG-FreeCombat/releases).

| Архив | Назначение |
|---|---|
| FreeCombatPrototype-0.8.11.zip | Основной аддон, обязателен |
| FreeCombatDiagnostics-0.2.2.zip | Необязательный журнал ошибок, маркеры и отдельные тестовые режимы |
| LonaPerformance-0.1.13.zip | Необязательные оптимизации геометрии и обработки событий |
| FreeCombatCompatibility-0.1.1.zip | Дополнительный мост для перечисленного ниже набора модов |

1. Закройте игру. Сделайте резервную копию игры и всей папки UserData. Для тестирования используйте отдельную копию игры.
2. Распакуйте нужные ZIP в корень этой копии: структура уже содержит `ModScripts/_Mods/`. Не создавайте вложенную папку ModScripts/ModScripts.
3. Включите аддоны в штатном менеджере модов. Порядок: сторонние моды → FreeCombatPrototype → FreeCombatCompatibility (если нужен) → FreeCombatDiagnostics → LonaPerformance.
4. Полностью перезапустите игру. Свободный режим включается при обычной новой игре или загрузке; тестовое снаряжение в сюжетной игре не выдаётся.

При обновлении заменяйте только папки этих аддонов при закрытой игре, сохраняя UserData и свои настройки `LonaPerformance/settings.rb`. Сохранения с FreeCombat требуют включённого FreeCombat: загрузка без него, удаление аддона и откат версии не поддерживаются. Для набора с RolePlay-S нужна **новая игра**; перенос старого персонажа в RolePlay-S не предусмотрен. Файлы `.free-combat.bak` — предыдущие версии перезаписанных сохранений; храните и обычную отдельную резервную копию.

Игра, движок и сторонние моды в архивах отсутствуют. Другие версии игры, другие движки и произвольные сочетания модов не заявлены как совместимые. Не меняйте Game.ini Title: штатный менеджер читает оттуда версию игры.

## Управление

| Действие | Клавиша |
|---|---|
| Движение | Назначенные в настройках игры клавиши; WASD поддерживается |
| Обычный / тяжёлый / контрольный приём | Z / C / V |
| Стрельба из подходящего оружия | Shift или обычный приём оружия |
| Взаимодействие | E / Enter |
| Меню | M |
| Пауза свободного боя | Space |

Бег, скрытность, экипировка и навыки сохраняют игровые требования. Направление стрельбы выбирается по ближайшей из четырёх осей; при точной диагонали выбирается вертикаль.

## Проверенный набор сторонних модов

Версии и порядок до FreeCombat:

1. RolePlayS 0.7.9.3.
2. _GrayRat_CustomNPCchs, _LoliMama_CustomNPCchs, _Milo_CustomNPCchs, _Musketeer_CustomNPCchs, DedGirl_chs, OrkindSlayerGirl_chs — по 1.0.
3. LonaRpgCoockingExpanded 0.5.0.
4. Temper Trine 1.5.2 (папка `Temper Trine`, ID `temper_trine`).
5. LonaRPG_FactionClashes 0.3.22.
6. LonaRPG_RestJournal 3.5.
7. PassiveStaminaRegen — предоставленная legacy-версия без номера.

С Compatibility исправлены восстановление STA, пауза счётчиков Temper, явные взаимодействия Faction Clashes, откат контекста при неудачной загрузке, уклонение RolePlay-S и журнал добавленных карт. Проверены основные взаимодействия, создание персонажа Adventurer, сохранение/загрузка и переходы. Это не полное прохождение каждого мода: все классы, ветки уникальных NPC и интерфейс мини-игры готовки ещё требуют проверки. Дистрибутивы модов нужно получить отдельно у их авторов.

## Диагностика и сообщения об ошибках

В основном аддоне нет отладочной панели или тестовых уровней. С включённым Diagnostics:

- F9 показывает/скрывает панель; при запуске она скрыта.
- F11 отмечает проблему без остановки игры.
- F6 из главного меню открывает изолированную арену, F7 — временный тест на карте; F8 возвращает из теста в главное меню. В F6 сброс — F5. Сохранение в тестах заблокировано.

После проблемы нажмите F11 и создайте [Issue](https://github.com/Sharaj00/LonaRPG-FreeCombat/issues): версия игры и аддонов, порядок модов, шаги, ожидаемое и фактическое поведение. Приложите журналы `UserData/FreeCombatDiagnostics/diagnostics.jsonl`, `.jsonl.1`, `.jsonl.2`, если они есть. Сначала просмотрите их: журналы содержат локальные пути и сведения о игровой ситуации. Не публикуйте личные файлы и сохранения без необходимости. Это локальная запись, автоматической отправки нет.

## Производительность и ограничения

LonaPerformance уменьшает стоимость отдельных расчётов геометрии и диспетчеризации. Библиотека `geometry-x86.dll` — собственный арифметический код, не замена RGSS. Каждую оптимизацию можно отключить в settings.rb. Экспериментальный GC по умолчанию выключен (`GC_BATCH_FRAMES = 0`); оставьте так для обычной Beta. Гарантий 60 FPS или ускорения на любой карте нет. Не устанавливайте одновременно старые отдельные патчи RGSSPerformance.

Перед финальным стабильным релизом остаются полное прохождение, длительные бои, редкие сюжетные состояния, непроверенные сочетания навыков и ручная оценка производительности. Публикация Beta позволяет собрать эти результаты от игроков.

## Исходники и сборка

Собственные исходники четырёх аддонов находятся в `src/`; арифметическое ядро и модули оптимизации — в `src/RGSSPerformance/`. `tools/build_geometry.ps1` собирает DLL с MSVC x86, затем `python tools/build_beta_release.py` формирует архивы и SHA256SUMS. Переданный `-Compiler` должен указывать на x86 cl.exe. Закоммиченные архивы в releases/ — проверенные файлы этой Beta; публикация сверяет их контрольные суммы.

Права на LonaRPG, RGSS и сторонние моды принадлежат их авторам. Их код, ресурсы и дистрибутивы здесь не распространяются. Отдельная открытая лицензия на собственный код пока не выбрана; наличие исходников не означает передачу прав на игру или сторонние материалы.
